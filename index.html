How it works

An international Elo rating predicts each match. The engine "calls" only clear favorites (A+ setups) and stays silent on close games. It is a two-way predictor — a draw is never the single most likely outcome, so it is shown but never the call. Validation is historical (holdout); live track record builds during the tournament.
